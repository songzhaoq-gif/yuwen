二年级全科复习宝｜Apple Pencil 手写识别版

上传方法：
1. 解压本 ZIP。
2. 打开 GitHub 的 yuwen 仓库。
3. 上传解压后的所有文件，不要上传 ZIP 本身。
4. Commit changes。
5. 打开 https://songzhaoq-gif.github.io/yuwen/?v=5 测试。

说明：
- 语文默写改为田字格手写识别。孩子用 Apple Pencil 写在输入格里，iPad 系统会识别成汉字，本 App 自动判断对错。
- 手机没有 Apple Pencil 时，可以点击田字格打字测试。
- 单元默写随机顺序，但每单元所有词语都会出现，不抽样，不遗漏。
- 语数英三科都包含，桌面图标已改为“语/数/英”三科合一。
